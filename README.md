# DevOps-Mastery

Personal Obsidian vault of hands-on DevOps / Cloud engineering notes — Linux, Python, Git, Docker, Kubernetes, AWS, Azure, GCP, Terraform, CI/CD, monitoring, deployment — built while transitioning into a Cloud/DevOps Engineer role.

## Open it

1. `git clone https://github.com/aakash-1004/DevOpsMastery.git`
2. Obsidian → **Open folder as vault** → select the DevopsMastery `DevopsMastery` folder (the `.obsidian` config and the bundled **AnuPpuccin** theme are at the repo root).
3. Open `00-Home/Home.md` and pin it. Everything is reachable from there; every note also has `↑ up · ← prev · → next` links under its title.
